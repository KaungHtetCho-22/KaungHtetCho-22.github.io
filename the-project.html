Exactly What to Build
Core Concept A ReAct-style multi-agent loop: one orchestrator LLM plans and delegates; specialist agents execute. The user types a goal in plain English. The system figures out the rest.
Orchestrator Qwen2.5-7B-Instruct Q4_K_M llama.cpp / Ollama
Already proven on your RTX 3060. No cloud costs.
Specialist Agents RAG Agent — pulls from Qdrant vector store (reuse DocRAG)
Code Agent — writes + executes Python in a sandbox
Search Agent — web search with citation tracking
